プライバシーポリシー

Spiritual Uploader／最終更新日：2026年9月29日

Spiritual Uploader は、運営者が自身の YouTube チャンネルと TikTok アカウントへ、自ら制作した動画を投稿するためだけに使う個人用ツールです。一般の利用者向けには提供していません。

1. 取得する情報

運営者本人が許可した範囲で、次の情報だけを扱います。

  • YouTube：動画のアップロードに必要なアクセス権（youtube.upload）と、チャンネル名の確認（youtube.readonly）
  • TikTok：表示名などの基本情報（user.info.basic）と、動画の下書き送信（video.upload）

2. 利用目的

取得した情報とアクセス権は、運営者自身のアカウントへ動画を送信するためだけに使います。広告・分析・第三者への提供には使いません。

3. 保存と管理

アクセストークンは運営者のパソコン内にのみ保存し、外部のサーバーには送信・保存しません。運営者はいつでも各サービスのアカウント設定から、本ツールへの許可を取り消せます。

4. 第三者への提供

法令に基づく場合を除き、第三者に情報を提供することはありません。

5. YouTube API サービスの利用について

本ツールは YouTube API サービスを使用しています。本ツールを利用することで、YouTube 利用規約に同意したものとみなされます。YouTube API サービスを通じて扱う情報には、Google プライバシー ポリシーも適用されます。

本ツールに与えた許可は、Google アカウントのセキュリティ設定（サードパーティ製アプリのアクセス権）からいつでも取り消せます。取り消した場合、本ツールが保存しているアクセストークンは使えなくなり、運営者のパソコンからも削除します。

本ツールは、Cookie その他の技術により利用者の端末に情報を保存・取得することはありません。

Privacy Policy (English)

Spiritual Uploader is a personal tool used solely by its operator to upload videos they created to their own YouTube channel and TikTok account. It handles only what the operator has authorized (YouTube: youtube.upload, youtube.readonly; TikTok: user.info.basic, video.upload), uses it only to send videos to the operator's own accounts, never for advertising or analytics, and never shares it with third parties. Access tokens are stored only on the operator's computer and can be revoked at any time from each service's account settings, including Google's security settings page. The Tool uses YouTube API Services; by using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies. The Tool does not store or access information on users' devices via cookies or similar technologies.
